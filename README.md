# Он меня найдёт

*He Will Find Me*

Короткая грустная игра про старую электронную игрушку. Она включается посреди свалки и уверена, что просто потерялась. Мальчик Миша её найдёт, он всегда находит.

Игрок смотрит на мир глазами игрушки по имени Пип. Сканером ищет на свалке вещи, в которых ещё теплится жизнь, и чинит их в мини-играх: настраивает диафильм, набирает номер на дисковом телефоне, заводит будильник, ловит волну на магнитоле, подбирает пароль к старому компьютеру. Каждая ожившая вещь возвращает Пипу воспоминание о Мише.

## Об игре

- Прохождение занимает 10–15 минут.
- Языки: русский и английский.
- Сделана на Ludum Dare за 2,5 дня, тема «старые технологии».

Батарейка Пипа садится после каждой главы и за каждую ошибку в мини-игре. Если заряд кончится, главу придётся начать заново. Часть подсказок спрятана на свалке, их нужно найти самому.

## Управление

- Мышь: клик, зажатие, перетаскивание.
- Пробел: пропустить реплику или перейти дальше.
- Стрелки: точная настройка радио.
- F11 или Alt+Enter: полный экран или окно (в десктопной версии).

## Запуск из исходников

Нужен [Godot 4.7](https://godotengine.org/download) и Git LFS: арт, звук и шрифты лежат в LFS.

```bash
git lfs install
git clone https://github.com/zhr0451/memory.git
cd memory
godot --path .
```

На десктопе игра запускается на весь экран.

Проверки:

```bash
godot --headless --path . --import
godot --headless --path . -s tests/test_runner.gd
godot --headless --path . -s tests/smoke_playthrough.gd
```

Первая команда проверяет, что скрипты и ресурсы разбираются без ошибок. Вторая запускает юнит-тесты. Третья проходит всю игру без ввода и в конце печатает `SMOKE OK`.

Веб-сборку собирает `tools/export_web.sh` (нужны шаблоны экспорта Godot). При пуше в `main` CI прогоняет тесты и выкладывает игру на GitHub Pages, а при пуше тега `v*` ещё и публикует релиз с архивом.

## Устройство проекта

Код на GDScript, архитектура MVVM, каждая фича целиком живёт в своей папке:

```
core/       состояние игры, тексты, музыка, менеджер сцен, настройки
features/   свалка, мини-игры, воспоминания, финал, HUD героя
shared/     общие шрифты, звуки, элементы интерфейса
tests/      раннер тестов, дымовой прогон, инструмент скриншотов
docs/       геймдизайн, архитектура, ассеты, публикация
```

Подробности в [docs/](docs/): [геймдизайн](docs/game-design.md), [архитектура](docs/architecture.md), [соглашения](docs/conventions.md), [инструменты](docs/tooling.md), [публикация](docs/publishing.md).
