# Фича-лист (v2, 17 октября)

Приоритеты: **must** — без этого игры нет, **should** — сильно улучшает, **could** — если успеем. Часы — оценка. Итого: must ~18 ч, should ~8 ч, could ~6 ч.

| Группа | Фича | Что делает | Приор. | Ч |
|---|---|---|---|---|
| Ядро | Менеджер сцен | Переходы свалка ↔ мини-игра ↔ воспоминание ↔ финал, затемнения | must | 1,5 |
| Ядро | Состояние игры | Текущая глава, пройденные предметы, какой открыт следующим | must | 1 |
| Ядро | Тексты из JSON | Все реплики и подписи в одном файле, правятся без кода | must | 0,5 |
| Ядро | Веб-сборка | Экспорт HTML5, пробная сборка в спринте 0 | must | 1 |
| Герой | Лицо + батарейка | Миниатюра лица в нижнем углу, батарейка на 5 состояний | must | 1 |
| Герой | Смена эмоций | 7 состояний по событиям сюжета | must | 0,5 |
| Герой | Реплики | Окошко рядом с лицом, печать по букве, 9-slice рамка | must | 1 |
| Герой | «Дыхание» лица | Масштаб ±2%, мерцание экрана, дрожь на «страх» | should | 0,5 |
| Свалка | Точки интереса | Кликабельный предмет с блеском, доступен только следующий по сюжету | must | 1 |
| Свалка | Зум камеры | Наезд к предмету (до ~1,3×) и отъезд | must | 1 |
| Свалка | Улики | Кликабельные детали: «страх» + успокаивающая реплика | could | 1,5 |
| Мини-игры | Диафильм | Угол ручки → резкость; решено при чёткой картинке 1 с | must | 2 |
| Мини-игры | Будильник | Кнопки часов/минут; решено при совпадении с подсказкой (07:30) | must | 1,5 |
| Мини-игры | Кассетный плеер | Перемотка и Play, 3 фрагмента на плёнке, катушки вращаются | must | 2,5 |
| Мини-игры | Кнопка «назад» | Выход из мини-игры на свалку | must | 0,5 |
| Мини-игры | Видеокамера | Угол ручки ослабляет помехи, после решения — финал | should | 2 |
| Мини-игры | Подсказка | Через 30 с бездействия нужная деталь мигает | should | 0,5 |
| Нарратив | Вступление | Чёрный экран, писк, лицо включается, свалка проявляется | must | 0,5 |
| Нарратив | Слайд-шоу воспоминаний | 2–3 кадра, подпись, «клик — дальше», покачивание и медленный наезд | must | 1,5 |
| Нарратив | Финал | Комната, «грусть», последняя реплика, батарейка 0, экран гаснет, титры | must | 1 |
| Сок | Шейдер плёнки | Зерно, виньетка, тёплый тон для воспоминаний | should | 1 |
| Сок | Шейдер помех | Полосы и шум, сила параметром | should | 1 |
| Сок | Звук | Эмбиент, звуки устройств, мелодия героя | should | 2 |
| Сок | Замедление мелодии | С каждой главой медленнее, в финале обрывается | should | 0,5 |
| Обвязка | Главное меню | Название, «Начать», громкость | could | 1 |
| Обвязка | Запасная мини-игра | Радио, телефон, приставка, машинка | could | 3 |

Заметки: покадровой анимации нет — всё движение твины/шейдеры. Если горит: видеокамеру убираем, после плеера сразу финал.

## Отображение на папки (feature-first)
| Фича | Папка |
|---|---|
| Менеджер сцен, состояние игры, тексты, события | `core/` (`scene_manager`, `game_state`, `texts`, `events`) |
| Лицо, батарейка, реплики, дыхание | `features/hero_hud/` |
| Вступление | `features/intro/` |
| Свалка, точки интереса, зум, улики, подсказка | `features/junkyard/` |
| Диафильм / Будильник / Плеер / Видеокамера | `features/minigame_projector/`, `minigame_clock/`, `minigame_tape/`, `minigame_camera/` |
| Слайд-шоу воспоминаний | `features/memory_slideshow/` |
| Финал и титры | `features/finale/` |
| Шейдеры, звук | `features/fx/`, `features/audio/` |
| Главное меню | `features/main_menu/` |
