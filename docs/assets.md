# Ассет-лист (v3)

## Правила экспорта
- Сцены рисуются целиком на холсте **1920×1080**, каждая деталь на своём слое; экспорт — отдельный PNG с прозрачностью, обрезанный по содержимому.
- Лицо героя и батарейка — отдельные маленькие холсты (интерфейс).
- Всё, что вращается — отдельный файл, центр вращения посередине.
- Палитра 4–6 цветов: свалка холодная серо-синяя, воспоминания тёплые янтарные.
- Бинарные ассеты лежат в `features/<фича>/assets/` и идут через Git LFS.

## Арт (v3, 19 октября: 6 предметов — диафильм, телефон, будильник, магнитола, компьютер, видеокамера)

**Сразу в игре** — код сам подхватит файл с таким именем и размером. **Нужен код** — после отрисовки программист подключает слой.
Где размер точный, код растягивает картинку ровно в него: рисовать именно в этих пропорциях.
